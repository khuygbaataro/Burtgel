# Бүртгэлийн веб

Овог, нэр, утасны дугаар, имэйл хаягийг `Register.db` SQLite өгөгдлийн санд хадгална. Имэйлийг `bat@example.com` жишээтэй ижил `хэрэглэгч@домэйн.com` хэлбэрээр сервер талд шалгана. Админ `Register.db`-д хадгалсан бүртгэлүүдийг веб хуудсаар харж, Excel файл болгон татаж авна.

## Ажиллуулах

1. Python 3.9 ба түүнээс дээш хувилбар суулгана.
2. Энэ хавтсанд терминал нээгээд хамаарлуудыг суулгана:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

3. Веб аппыг эхлүүлнэ:

   ```powershell
   $env:ADMIN_PASSWORD = "өөрийн-урт-нууц-үг"
   python app.py
   ```

4. Хөтөчөөр `http://127.0.0.1:5000` хаягт орно.
5. Админ хуудас нээхийн тулд `http://127.0.0.1:5000/admin` хаягт орж, дээр тохируулсан нууц үгээр нэвтэрнэ. **Excel татах** товчоор мэдээллээ татаж авна.

`ADMIN_PASSWORD` нь зөвхөн тухайн PowerShell цонхонд тохируулагдана. Аппыг дахин эхлүүлэх үед дахин тохируулна. Өгөгдлийн сан төслийн хавтаст `Register.db` нэрээр үүснэ. Өмнөх `Register.xlsx` файл байвал анхны эхлүүлэлтээр бүртгэлүүдийг SQLite-д нэг удаа автоматаар хуулна; хуучин файлыг өөрөө устгахгүй.
